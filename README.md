# 709 系列等車時間

桃園公車 709、709A、709B、709C 的即時等候時間，手機與電腦皆可瀏覽，每 30 秒自動更新。

**網址：https://teds-lin.github.io/bus709/**

## 顯示內容

只顯示等車的所在位置（上車站）：

| 方向 | 上車站 | 顯示路線 |
|---|---|---|
| 龍潭 → 永寧 | 龍潭中正路 | 709、709A、709B、709C |
| 永寧 → 龍潭 | 永寧轉運站 | 709、709B、709C（709A 無此方向，不顯示） |

- 每站的路線依「最快到站」排序，並顯示車牌、下一班、末班車。
- 等候時間顏色：3 分內紅色、10 分內橘色、更久綠色。
- 下方「停靠站」區塊列出各班次從上車站到下車站依序停靠的站；停靠順序相同的路線合併成一張卡（例如 709A 往永寧多停「龍潭轉運站」）。

### 狀態文字

| 顯示 | 意思 |
|---|---|
| `X 分` | 即時預估（依車上 GPS） |
| `進站中`／`即將進站` | 車輛即將抵達 |
| `約 X 分`（備註「表定 HH:MM」） | 車輛尚未發車，表定時間在 30 分鐘內，依表定時間換算 |
| `即將發車` | 表定時間就是現在 |
| `預定 HH:MM` | 車輛尚未發車，表定時間超過 30 分鐘 |
| `尚未發車` | 尚未發車，也沒有表定時間 |
| `末班駛離` | 今日末班車已開走（與官方網站用語一致） |
| `改道不停靠` | 施工或活動改道，不停此站 |
| `今日未營運` | 今日不營運 |
| `查無路線` | 官方資料中找不到這條路線（資料異常） |

注意：永寧轉運站是發車站，系統會把「即將進站、到站後折返發車」的車也算進預估，實際離站時間可能比顯示的晚。709B 從永寧回程的班次很少（集中在清晨、中午與深夜），晚上多半要等很久。

### 連線失敗時

- 曾經成功過：保留上次的資料，頂端顯示黃色提示「顯示的是 X 分鐘前的資料」；資料超過 2 分鐘未更新時，等車卡片變淡。
- 從來沒成功過：顯示紅色錯誤。
- 失敗後前 3 次每 5 秒重試，之後恢復每 30 秒；連續失敗 3 次以上會附上官方網站連結。
- 頁面切到背景時暫停更新，回到頁面時立即更新。

## 技術說明

- 單一靜態檔 `index.html`，不需後端、不需金鑰，部署在 GitHub Pages（`main` 分支根目錄）。
- 資料來源：[桃園市公車動態資訊系統](https://ebus.tycg.gov.tw/ebus/) 的 GraphQL 介面 `https://ebus.tycg.gov.tw/ebus/graphql`（CORS 開放，瀏覽器可直接呼叫）。一次查詢取回 4 條路線的 `estimateTimes` 與 `stations`。
- 路線代碼（xno）：709＝`709`、709A＝`7091`、709B＝`7092`、709C＝`7093`。
- 方向判斷：在每條路線同一個 `goBack` 的停靠序列中，「龍潭中正路」排在「永寧轉運站」之前＝往永寧，之後＝往龍潭。不寫死站牌代碼，因此：
  - 709C 環狀線（中正路經過兩次）也能正確分向；
  - 同一站名在不同路線用不同站牌代碼（例如往永寧的中正路，709B 是 8414、其他是 6146）也不受影響；
  - 路線調整停靠站時頁面會自動跟著變；709A 若加開回程也會自動出現。

## 風險

此 GraphQL 介面是公車動態網站自用、非正式公開 API，沒有文件也不保證不變。若改版失效，頁面會顯示錯誤並引導至官方網站；屆時可改用交通部 TDX API（需申請金鑰，須透過中繼服務如 Cloudflare Worker 保護金鑰）。
