# 709 系列等車時間

桃園公車 709、709A、709B、709C 在「龍潭中正路」與「永寧轉運站」兩站的即時等候時間，手機與電腦皆可瀏覽，每 30 秒自動更新。

- 資料來源：[桃園市公車動態資訊系統](https://ebus.tycg.gov.tw/ebus/) 的 GraphQL 介面（瀏覽器直接呼叫，不需金鑰、不需後端）。
- 方向判斷：在每條路線的停靠序列中，「龍潭中正路」排在「永寧轉運站」之前＝往永寧，之後＝往龍潭；因此 709C 環狀線也能正確分向，站牌代碼變動時不需改程式。
- 709A 只有往永寧單向，往龍潭欄位顯示「無此方向」。

注意：此介面為公車動態網站自用、非正式公開 API，若改版失效，頁面會顯示錯誤並引導至官方網站。
